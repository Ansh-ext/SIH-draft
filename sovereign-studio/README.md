# Sovereign AI Workbench — Enterprise Air-Gapped Intelligence Platform

An enterprise-grade, 100% offline, air-gapped document intelligence platform with a "Linear-app" inspired dark UI built using **React**, **Vite**, and **Tailwind CSS**.

---

## 🚀 Tech Stack & Setup

- **Frontend Core:** React 18+ (Vite setup with fast HMR)
- **Styling:** Tailwind CSS (Dark theme with Emerald `#35E6A4` accent)
- **Icons:** Lucide React (`lucide-react`)
- **Routing:** React Router DOM

### Getting Started (Frontend Local Setup)

```bash
# Install dependencies
npm install

# Run frontend development server
npm run dev

# Build for production distribution
npm run build
